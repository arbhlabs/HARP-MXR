Built for hands-on mixing

Live sources meet tactile control.

HARP//MXR combines file decks, per-app live capture and controller-first performance in one Windows mixer.

◫

File + live decks

Load local tracks or select a running app/process as a live source. Supported file formats depend partly on installed Windows codecs.

◉

Shape every transition

Each deck has EQ with kills, filter and performance effects. Crossfader, auto-gain and limiter shape the output.

↗

Auto Mix

Use analyzed tempo, key and phrasing to plan transitions. Choose MIX NOW or SKIP, and take manual control at any time.

⌁

Controller workflow

Switch profiles, remap inputs and use Stick FX. A second controller can run a dedicated FX Pad profile.

◎

Track analysis

Remember Tracks stores local waveform peaks, fingerprints, analysis and available metadata to recognize tracks played live.

⟲

Local by design

No account or app telemetry. Settings, logs, analysis and captured sample-pad audio are stored locally.
